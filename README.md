# grouch

The off-switch for AI flattery. One trigger phrase, three levels of honesty.

Every AI assistant has the same problem: it flatters you. "Great question!" before the answer, validation before the substance, softening before the bad news. Grouch turns the glaze off.

## The dial

| Level | Trigger | Behavior |
|---|---|---|
| low (default) | `grouch mode` or `/grouch` | Blunt. No hedging, no compliments, no softening. Full reasoning, diplomacy dead. |
| high | `/grouch high` | No mercy. Cold verdict first, steelman-then-kill teardown with verified facts, or a flat dismissal. Praise rationed. |

`stop grouch` / `grouch off` reverts.

## Install

Copy `skills/grouch/` into your agent's skills folder. One `SKILL.md`, no dependencies, no build step.

## Why this exists

The labs wrote "don't be sycophantic" in their own spec sheets and shipped the glaze anyway. Nobody packaged the off-switch. So here it is, with a dial.
